# COBOTTA Pick V3：座標一覧の表示修正

V2への差分更新です。既存アプリのファイルを残したまま適用してください。

## 適用方法
1. 起動中のアプリを停止します。
2. ZIPを展開し、`app.py`と`templates/index.html`を既存の`cobotta_pick`フォルダーの同じ場所へ上書きします。
3. `app.py`を起動し、ブラウザを再読み込みします。

`config.json`、`robot.py`、`.venv`、`.git`などは変更不要です。設定値・速度・動作順序・ハンド制御は変更していません。

## 原因と修正
V2では実機ピック開始時に実行用候補を無効化する際、表示用の対象・座標も消していました。自動運転では認識直後にピックへ進むため、画面に表示される前に消えることがありました。

V3では実行用候補と表示用データを分け、対象名・順番・XYZ・Rz・画像角度と画像上のマーカーを実行中および終了・中断後も残します。実行用候補は従来どおり動作開始前に無効化します。確認用の表示が残っていても、実機ピック・模擬実行ボタンは無効です。次の撮影・画像読み込み・認識などで古い表示を更新します。

## 検証
既存テスト23件と表示保持に関する追加テスト4件、計27件が成功しました。実行中・終了後のAPI応答、実行後の再実行拒否、異常・停止後の表示保持、次回撮影時の消去を確認しました。画面のJavaScriptも模擬状態で表示とボタン制御を確認済みです。実機およびGemini APIへの接続は行っていません。

テスト用ファイルも同梱しています。既存の`test_app.py`がある環境で次のように実行できます。

```powershell
.\.venv\Scripts\python.exe -m unittest test_app test_automatic test_display -q
```
