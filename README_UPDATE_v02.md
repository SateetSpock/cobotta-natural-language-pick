## スタートから全自動（Gemini方式）

1. 実機設定を入力・確認します。Tool=0、Work=0、把持力10 Nを今回の使用値として初期表示します。確認チェックは自動では入りません。
2. 実物を見て「緑色の金魚を1個、その後に黒色の金魚を1個」のように指示します。
3. APIキーを入力し、方式に「Gemini」を選択します。
4. 「スタート（撮影からピックまで）」を押します。

未接続なら接続し、P10へ移動→開放30 mm→撮影→Gemini認識→座標変換→順番にピック→P10へ戻る、まで進みます。
途中の「候補を取得」「実機ピック」ボタン操作は不要です。候補表示後の承認待ちもありません。
対象が見つからない場合はP10で終了します。API失敗や不正な座標の場合はピックへ進みません。
一度のスタートでGemini認識は1回です。複数個の途中では再認識しません。

## JSON方式（API不要）

1. 方式を「JSON」に切り替えます。
2. 開いたJSON欄へ対象のJSONを貼り付けます。
3. 「スタート」を押します。

こちらもP10移動・開放・撮影から始めますが、Geminiを呼ばず、貼り付けた座標を使用します。
新しい写真からJSONの対象を探し直す処理はありません。JSONと実物の配置が一致しているときに使ってください。
Geminiで得られた結果もJSON欄へ自動反映されます。必要ならコピーして保存できます。
APIキーは保存しません。JSON欄もブラウザ再読み込み後に手入力内容を保持する仕組みではありません。

単体の形式、配列、targetsで包んだ配列に対応します。pointは[x,y]順、0〜1000です。

```json
{"targets":[{"label":"緑色の金魚","point":[380,645],"closing_angle_deg":150}]}
```
