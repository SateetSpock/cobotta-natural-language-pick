COBOTTA Pick 更新 V4

適用方法
1. 起動中のアプリを停止します。
2. 現在のapp.pyをバックアップします。
3. このZIPのapp.pyを 既存のcobotta_pickフォルダー内のapp.py に上書きします。
4. いつもの方法で起動し、ブラウザを再読み込みします。

V3の表示修正版を基にしています。V3以降にapp.pyを独自変更している場合は、その変更との統合が必要です。
config.json、robot.py、geometry.py、templatesは上書きしません。

変更内容
Geminiに送る固定プロンプトへ、上から接近する平行2爪ハンドの把持ルールを追加しました。
ピック前の開き幅はconfig.jsonのopen_mmを読み取り、キャリブレーションのimage_pointsとrobot_pointsも実寸の基準として送ります。
細長い物体は長い側面を挟み、幅方向に閉じます。USBは端子や穴、金魚は目玉やひれを避け、本体を選びます。
対象と順番だけ入力しても、これらの条件を毎回送信します。
入力例：白いUSBメモリを1個、その後にオレンジの金魚を1個取って。

座標変換・実機動作・速度設定・JSON直接入力の処理は変更していません。
実寸情報はAIの候補選定の参考です。爪の厚み・長さは未設定であり、数値による衝突判定を追加したものではありません。

確認内容
Python構文、設定値からのプロンプト生成、JSON出力例、他の処理に変更がないことを確認しました。
Gemini APIの実呼出しと実機動作は、この更新では実施していません。
